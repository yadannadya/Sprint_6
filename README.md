## Финальный проект 6 спринта
Автотесты для сервиса «Яндекс.Самокат».
https://qa-scooter.praktikum-services.ru/

Впроекте использован:

-Page Object
-Allure
-pytest==9.0.0 
-selenium==4.38.0 
-webdriver_manager==FirefoxDriver

Написаны тесты для сценариев:

1.Выпадающий список в разделе «Вопросы о важном». При нажатии на вопрос, открывается соответствующий текст. 
2.Заказ самоката с двумя наборами данных для разных точек входа: кнопка «Заказать» вверху страницы и внизу.
3.Переход по ссылке в логотипе «Самоката», логотипе Яндекса

### <h>1. Установите зависимости:</h>

> pip install -r requirements.txt</h>

### <h>2. Запустить все тесты и записать отчет:</h>

> pytest --alluredir=./allure-results

### <h>3. Посмотреть отчет по прогону html</h>

> allure serve ./allure-results
